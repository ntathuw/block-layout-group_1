## Discussion Points

| Topic | Discussion Summary |
| :--- | :--- |
| **Thảo luận chi tiết Class User & Account (Thắng, Thư)** | Review & thống nhất thiết kế OOP kế thừa `AUser`/`AAccount`. Class `Account` kế thừa `AAccount` hỗ trợ xác thực role 'user', ghi phiên vào table `session` bằng callback (`isLogin`, `login`). Class `User` kế thừa `AUser` với các private fields theo chuẩn GitHub Profile (`#username`, `#bio`, `#socialAccounts`) và validate username regex, `websiteUrl`. |
| **Thiết kế HTML/CSS cho trang Login (Thư)** | Đã hoàn thiện file `login.html` và `login.css` áp dụng chuẩn BEM (`login-card`, `login-form`, `login-oauth`, `site-footer`). Tối ưu giao diện dark theme GitHub, responsive cho màn hình di động (<767px) và tinh chỉnh spacing, font size, button hover states. |
| **Xây dựng JavaScript xử lý Login (Thắng, Thịnh)** | Triển khai file `login.js` sử dụng `XMLHttpRequest` đọc dữ liệu JSON Lines từ `user.txt` và `account.txt` vào `fileStore`. Tích hợp `authService.login` xử lý xác thực callback, hiển thị lỗi động trên form (`.login-form__error`) và chuyển hướng về `index.html` khi đăng nhập thành công. |

## Decisions Made

| Decision | Rationale |
| :--- | :--- |
| **Thống nhất cấu trúc OOP cho User & Account Class** | Đảm bảo mã nguồn đóng gói chặt chẽ (Private Fields `#`), kế thừa abstract class `AUser`/`AAccount` chuẩn xác và xử lý bất đồng bộ thông qua Callback nhất quán trong dự án. |
| **Thống nhất giao diện HTML/CSS trang Login theo chuẩn BEM** | Giúp code UI sạch, dễ bảo trì, đúng layout GitHub Login và responsive tốt trên các thiết bị di động. |
| **Sử dụng XMLHttpRequest & JSON Lines cho luồng đăng nhập JS** | Phù hợp với kiến trúc lưu trữ dạng text file hiện tại của dự án, đảm bảo đọc ghi session mượt mà trước khi kết nối DB chính thức. |
