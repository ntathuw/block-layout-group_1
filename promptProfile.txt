Mình đang làm bài tập ở khoá học lập trình, phần này là dựng lại trang user profile của GitHub bằng HTML + CSS thuần.

Nhóm mình đã vẽ block diagram và chốt tên class theo BEM rồi. Có 2 file trong
repo, bạn đọc cả hai:

  design/v1_aug/profile/profile.png   -> ảnh bố cục, xem để biết cái gì nằm ở đâu
  design/v1_aug/profile/profile.xml   -> cấu trúc cây và tên class

File XML là chuẩn. Tên class và thứ tự lồng nhau lấy nguyên từ đó, không được
đổi, không được tự thêm class mới. Ảnh chỉ để hình dung bố cục và khoảng cách.

CÁCH MÌNH MUỐN LÀM VIỆC — phần này quan trọng nhất, đọc kỹ giúp mình:

Đừng viết luôn cả HTML với CSS ra một lượt. Mình muốn đi từng bước:

1. Đọc 2 file trên rồi lập plan: chia thành các task nhỏ, mỗi task làm xong là
   mở trình duyệt kiểm tra được ngay. Liệt kê plan cho mình xem, chưa code gì
   cả.
2. Mình duyệt plan. Ok thì mình báo, không ok thì mình sửa lại.
3. Chốt plan rồi thì bạn làm ĐÚNG MỘT TASK ĐẦU TIÊN, xong dừng lại.
4. Mình review và chạy thử. Ổn thì mình nói "ok, làm tiếp". Chưa ổn thì mình
   báo chỗ cần sửa.
5. Cứ vậy từng task một cho tới khi xong.

Đừng tự nhảy sang task tiếp theo khi mình chưa duyệt. Cũng đừng gộp hai ba
task vào một lượt trả lời cho nhanh — mình cần review từng bước một.

Phần commit git mình tự làm. Nhưng mỗi task xong thì gợi ý giúp mình một câu
commit message.

RÀNG BUỘC KỸ THUẬT:

- HTML + CSS thuần. Không framework, không Bootstrap, không Tailwind, không
  thư viện CSS nào hết.
- Chưa cần JavaScript, phần đó để sau.
- Tên class phải lấy đúng từ file XML. Thấy thiếu chỗ nào cần thiết thì hỏi
  mình trước, đừng tự đặt tên mới.
- Trong file XML mọi phần chữ đang để trống — bạn tự điền nội dung tiếng Anh
  cho giống trang GitHub thật.
- Giao diện theo GitHub dark theme.
- Responsive: desktop và mobile.
- Ghi vào: src/profile.html và src/css/profile.css
- Nút edit profile chỉ để hiển thị cho giống GitHub thật, không cần hoạt
  động.

Bắt đầu bằng plan giúp mình nhé.
