## 4. QUY TẮC ĐÃ PHỔ BIẾN 📌

### Thứ tự commit — quan trọng nhất, đề bài chấm trực tiếp

```
1. chore: init repo structure                                   ✅ đã xong
2. docs: define block list and naming convention
3. design: add hand-drawn block layout v1 (mobile + desktop)    ← ẢNH VẼ TAY
4. design: add draw.io block layout v1 + png export             ← DRAW.IO
   >>> git tag design-v1 <<<
5. feat: ... (code bắt đầu TỪ ĐÂY, không sớm hơn)
```

**Ba điều cấm:**

1. ❌ Commit vào `src/` khi tag `design-v1` chưa tồn tại
2. ❌ Gộp ảnh vẽ tay chung một commit với code
3. ❌ Chỉ commit file PNG mà thiếu file `.drawio` gốc

Trước khi code, chạy kiểm tra:

```bash
git log --oneline --decorate | grep design-v1
```

Không thấy tag → dừng, chưa được code.
